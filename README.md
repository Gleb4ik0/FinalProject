# Phone Book

https://gleb4ik0.github.io/FinalProject/

## Task

Create a website with a functional and adaptive phonebook using plain HTML, CSS and JS. This phonebook should contain entries with contact information, and provide opportunities for adding, editing, deleting, and searching records. The main goal is to demonstrate skills in working with HTML, CSS, and JavaScript, as well as the ability to organize and structure the project.

### Functional requirments

- At any time, the user should be able to return to the original state (e.g., canceling changes to a record).
- For form submission, use preventDefault to prevent page updates.
- Event handling:
  - Use event delegation whenever possible.
- Initial data:
  - The phonebook must have at least 4 records loaded initially.
- Data storage:
  - Do not use localStorage.

## Technologies used

- HTML5
- CSS3
- JavaScript

## Demonstrated skills

- Work with events and DOM.
- Create adaptive pages.
